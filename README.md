# 班级座次管理（座次2）

多个班级的座次、随机抽取、课堂记分、课堂表现与学生轨迹。纯本地网页：不需要安装，不联网，不上传任何学生信息。数据保存在“座次2”文件夹里，可以放在 U 盘上直接使用，并配合 SyncTime、OneDrive 同步。

## 一、打开与连接文件夹

1. 用 **Chrome 或 Edge** 双击打开 `座次管理.html`。
   - Mac、Win11：直接用 Chrome 或 Edge（Win11 自带 Edge）。
   - Win7：需要 Chrome 或 Edge，版本 86～109（Win7 最高只能装到 109）。网页打开时会自检，浏览器不合适会直接提示。
2. 点右上角 **📂 连接文件夹**，选择 **座次2** 文件夹（里面有“座次管理.html”），浏览器询问时点 **允许**。
   - 在同一台电脑上，下次打开一般只需点“重新连接”。在教室电脑上每次都要选一次文件夹（浏览器的安全限制）。
3. 右上角显示“✓ 已保存到文件夹”时，所有修改都已经写进文件夹。显示“⚠ 未保存”时点它重试（常见原因：U 盘被拔出）。

## 二、目录

```text
座次2/
├── 座次管理.html        # 入口
├── 数据/                # 正式数据（记录文件）。不要手动修改或删除
├── 导出/班级名/          # 导出的 Excel：名单、座次表、课堂表现（可打印、可在 Excel 里改）
└── 辅助资源/            # 程序、测试、工具（只在 Mac 上修改）
```

## 三、座次页（首页）

- **默认只显示一个班**，左上角下拉框切换班级。页面默认显示“今天生效”的座次（生效日期不晚于今天的最近一次定版）。
- **学生版 / 教师版**：学生版讲台在上方；教师版旋转 180°，讲台在下方。两版来自同一份数据。
- **性别颜色**：男生蓝色、女生红色，未标注为黑色。
- **随机抽取**：默认抽 1 人，也可点 2～6 或在“自定义”里输入人数。抽中的学生在座次表中金色高亮并标序号，座次表上方大字显示“姓名 · 第几排第几列”。勾选“本节课不重复”后，已抽过的人不再抽，全部抽完自动重新开始。
- **课堂记分**：点“★ 课堂记分” → 选一个表现项 → 点选 1 名或多名学生 → “确认记分”。记错了可以“撤销上一次”。电脑时间不准时，可以在“记分日期”里改。

### 排座工具（座次表下方，点开）

| 方式 | 说明 |
|---|---|
| 随机排座 | 可勾选“同桌尽量男女搭配” |
| 按成绩顺序选座 | 按名次从高到低，每人点一个空座；可跳过、撤销、剩余自动排 |
| 按成绩自动排 | 名次靠前的优先坐前排中间 |
| 前后 / 左右轮换 | 以上一次定版为基准：每列后移 N 排（最后几排移到最前），每排右移 N 列（最右移到最左）；可单开一个方向；空座和固定学生不动 |
| 沿用上次座次 | 座位不变，为新的一周另存一份 |

- **固定学生**：点“📌 固定学生”，再点学生即固定在当前座位；以上所有方式都会先安排固定学生。
- **标注性别**：点“♂♀ 标注性别”，再点学生：未标注 → 男 → 女 → 未标注。
- **生效日期**：新座次从这一天起生效。同一周只有一份定版；同一周再次定版会替换它（旧版仍留在记录里）。
- 生成的都是 **候选稿**，可“✎ 微调座位”（点两个座位对调，也可把学生挪到空座），满意后“★ 确认定版”。
- 定版时自动在 `导出/班级名/` 生成一份座次表 Excel（学生版 + 教师版），每次都是新文件，不覆盖旧的。
- 空座默认留在最后一排两侧。

## 四、其他页面

- **课堂表现**：按周（或全部）以座次表形式查看每人的加分、扣分；点学生看明细，可删除记错的记录；可导出 Excel、清空所选周。
- **学生轨迹**：某个学生在历次定版中的座位、前中后与左中右的覆盖次数，以及他的全部课堂表现记录。
- **班级设置**：
  - 新建、改名、删除班级；**导入名单**（Excel、CSV 或直接粘贴；自动识别姓名、性别、成绩/名次、学号、班级列，有“班级”列时一次导入多个班）。
  - 名单表：直接改序号、姓名、性别、成绩、学号、在班/离班。离班的学生不再排座，历史保留。
  - 座位布局：共几排、每排几列；点列之间的竖条设置走廊，点座位设为不可用。第 1 排靠近讲台。改布局只影响之后生成的座次。
  - 表现项：所有班级共用，可增删改。

## 五、在 Excel 里修改

导出的表都可以在 Excel/WPS 里直接改，保存后回到网页（或点“↻ 刷新”）会自动读入：

| 表 | 可以改的 |
|---|---|
| 名单-班级名-….xlsx | 姓名、性别（男/女）、成绩、学号、状态（在班/离班）；增删行（删掉的行 = 离班）。最后一列“系统编号”不要改 |
| 座次表-….xlsx | 在“学生版”里对调或挪动姓名（只能换座位，不能增删学生）；教师版由网页自动生成 |
| 课堂表现-….xlsx | 明细的删除、修改、新增（新增时填姓名、表现项目、日期即可，分值可留空） |

- 每张导出表里隐藏存着导出时的内容，网页只读入“你改动的部分”，所以打开一张旧表改了保存，也不会把之后的新数据改回去。
- Excel 不会自动保持最新；想看最新的就再导出一次，旧的导出文件可以随时删除。
- 改完请保存并关闭 Excel，再回到网页。

## 六、U 盘、SyncTime 与 OneDrive

网页 **只新建文件，从不修改、改名或删除已有文件**：每次打开网页并做了修改，会在 `数据/` 下新建一个记录文件，这次的操作都写进它，关掉后不再改动。打开网页时把所有记录文件合并起来。所以同一个文件不会在 Mac 和 U 盘两边都被改，SyncTime 双向同步、OneDrive 同步都不会因此冲突。

- 保持 SyncTime 的双向同步和“插上即同步”即可。建议在 SyncTime 的过滤里加上：`~$`、`.crswap`、`Thumbs.db`、`desktop.ini`（`.DS_Store` 已排除）。
- **不要** 手动修改或删除 `数据/` 里的文件（删除会被同步到另一边）。
- **不要** 在 U 盘上修改 `辅助资源/` 里的程序文件。
- 同一份导出的 Excel 不要在 Mac 和教室两边都改（那样 SyncTime 会报这一个 Excel 冲突；两边的改动网页都已读入，保留哪份都不丢数据）。
- 两台电脑在同步之前各自给同一周定版了：页面顶部会提示，默认采用较晚的一份，可一键“改用另一份”或“保留当前”。
- 在 Mac 上改了座次但没插 U 盘同步就去上课，教室里看到的仍是旧座次；回来插上 U 盘同步后会自动合并。
